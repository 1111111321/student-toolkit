关于本站

一个学生做的、给自己用的小工具站。

关于我

这里写你是谁、几年级、平时怎么安排学习时间。两三句话即可。

为什么做这个站

写真实的原因：比如「用过很多待办 App，功能太多反而懒得打开」，所以想做一个打开就能用的。

怎么做的

  • 纯 HTML / CSS / JavaScript，没有后端，没有数据库
  • 数据只存在你自己的浏览器里，不上传服务器
  • 用 Git 记录每一次修改
