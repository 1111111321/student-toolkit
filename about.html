About this site

A small toolkit built by a student, for students.

About me

I am a computer science student, and this site is my course project for web development. This project includes lots of practical functions.

How it is built

  • Plain HTML, CSS and JavaScript — no framework, no build step, no backend.
  • Every colour is a CSS variable, so dark mode is one class on the body.
  • Task data lives only in the page; nothing is stored or sent anywhere.
  • Every change is tracked with Git.

What I learned

  • How to build a page from scratch instead of filling in a template.
  • That dates need care: subtracting two dates gives milliseconds, and parsing a date string the obvious way can shift the answer by a day.
  • That accessibility is not extra work — labels, focus styles and a few aria attributes made the whole site usable from the keyboard.

Sources
